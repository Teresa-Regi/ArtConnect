## ArtConnect 

ArtConnect is an interactive art gallery website created using HTML, CSS, and Bootstrap. It showcases different artworks, artists, and detailed information about each artwork.

## Live Website
https://teresa-regi.github.io/ArtConnect/

## Technologies Used
- HTML
- CSS
- Bootstrap

## Features
- Login and Signup pages
- Art gallery homepage
- Individual artwork pages
- Artist details
- Responsive design
